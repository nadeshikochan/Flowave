Flowave 数据恢复

先完全退出 Flowave 和后台，再复制整个工作区保留现场。
安装版工作区位于你选择的数据文件夹，ZIP 默认使用程序旁 data。
启动失败窗口的“打开数据目录”可直接打开实际位置。

一、升级、重装或移动后
运行安装器选择“使用现有工作区”，或在软件的工作区入口打开原文件夹。
复制迁移仅在你主动选择时进行。外部音乐文件仍按原位置读取。

二、配置损坏
软件会尝试 config/app.json.previous，并保留损坏的 app.json.corrupt-*。
没有有效副本时会停止写入。退出后可从整个工作区的备份恢复配置。
保留现有文件，核对备份日期后再替换 config/app.json。

三、听歌记录
主文件损坏时软件会尝试最近有效的每日备份。
通常记录在 library/listening，兼容目录可能仍在 config。
在“数据与帮助 > 帮助与恢复”可查看实际备份与操作前快照。
手动恢复先复制现有记录，再将选定备份复制为记录目录的 listening_history.json。
保留原备份，重新打开后核对日期、次数和时长。

四、推荐索引和分析结果
曲库索引的 tracks.json 与 embeddings.npy 属于同一代，其 .previous 副本应成对保留。
不要单独替换其中一个。软件会校验完整代并尝试上一个有效版本。
SQLite 数据库运行中可能有 -wal 文件，备份和移动前应退出软件。
模型和缓存不能代替听歌记录及分析成果的备份。

五、仍无法恢复
保留整个工作区，暂缓删除或重新处理全库。
能打开软件时可在“数据与帮助 > 诊断日志”预览脱敏信息并导出。
报告问题时附软件版本、构建号和操作步骤，提交前检查个人信息。
