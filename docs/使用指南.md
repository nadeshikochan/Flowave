# 使用指南

## 添加音乐

1. 打开「设置 → 音乐库与在线 → 本地音乐」。
2. 添加音乐文件夹，点击「应用更改」。
3. 回到歌曲列表，双击歌曲播放。可以搜索歌曲、创建歌单或安排播放队列。

从曲库移除文件夹会停止扫描其中的歌曲，音乐文件仍留在原处。需要在线播放时，可在「音乐库与在线 → 在线音源与音质」导入可信音源脚本。

左下角「使用手册」有图文步骤。按 F1 或点击设置中的「本页帮助」可以打开当前页面的说明。

## 歌词与资料

点击播放栏的封面打开歌词页。「设置 → 歌词」可调整显示语言、字号、颜色和同步。桌面歌词移出屏幕时，点击「歌词 → 桌面歌词 → 恢复桌面歌词位置」。

右键本地歌曲，选择「歌曲资料…」可清空或编辑资料、更换封面，修改保存在工作区。「歌词…」可编辑、替换或删除 KTV 歌词文件。内嵌歌词可隐藏后恢复。

多首歌曲缺少资料时，可在「设置 → 曲库工具 → 歌曲资料与歌词补全」选择要检查的内容。已有合格歌词会跳过。

## 安装插件

打开「设置 → 插件与模型」，选择所需功能。软件会显示下载量及所需空间。涉及模型的插件需要兼容的 NVIDIA 显卡和驱动。安装完成后重启 Flowave。

- **歌曲推荐** 安装后，在「设置 → 歌曲推荐 → 准备与索引」更新全库索引。自然续播沿当前方向接歌，「找回感觉」根据最近听过的歌曲调整方向，「换个感觉」开启另一段。
- **歌曲分析** 可以准备歌曲标签和段落，随后在「曲库概览」组合筛选，或打开播放栏中的「歌曲分析」查看当前曲。
- **演奏练习** 可使用分轨、循环区间、变速和谱面辅助。具体模型许可见[第三方说明](../release-template/THIRD_PARTY_NOTICES.txt)。
- **听歌记录** 可以查看收听时长、播放次数和排名。

移除插件会保留相应记录、模型和分析结果。使用「工作区与存储」可打开存放位置。

## 工作区

安装时分别选择程序目录和数据目录。ZIP 便携版默认使用程序旁的 `data`。工作区保存音乐目录、设置、歌单、记录、插件和模型数据。模型、索引及分轨可能占用较大空间。

通过左下角「工作区」或「设置 → 数据与帮助 → 工作区与存储」新建、打开和切换。要搬动或备份工作区，请先退出软件，再复制或移动完整工作区。外部音乐目录需另外备份，移动后按需重新选择。

### 升级与卸载

安装版升级前退出 Flowave，运行新安装包并选用已有工作区。需要换盘时，可以由安装器复制旧数据。原目录保留。便携版解压到新目录后，通过「打开工作区」继续使用旧数据。

卸载默认保留工作区。选择清理时，请核对要删除的类别。下载的音乐和其他工作区保留。

### 恢复与诊断

「设置 → 数据与帮助 → 帮助与恢复」显示版本、构建号、备份和恢复入口。手动恢复前，请先退出软件并备份当前工作区。

「诊断日志」可以预览和导出诊断信息。提交问题前请查看预览内容，删除不想公开的信息。
