# 隐私与数据

Flowave无需账户，本地曲库、播放历史、索引和分析结果保存在本机。安装版使用安装时选择的数据目录，模型环境、下载和缓存也存入该目录。系统用户目录仅保留`%LOCALAPPDATA%/Flowave/data-location.txt`位置记录。ZIP便携版使用程序旁`data/`。通过环境变量指定目录时，以实际配置为准。

数据目录包含配置、曲库索引、历史、任务状态、歌词与封面缓存、日志等。音乐文件与模型可以位于独立目录。部分界面状态可能由 Electron 本地存储管理。

工作区通过`.flowave-workspace.json`记录格式与宿主协议版本。安装版的最近列表位于`%LOCALAPPDATA%/Flowave/workspace-history.json`，便携版的位置与最近列表在程序旁保存。最近列表只含文件夹路径，供本机打开使用。新建工作区独立初始化，已有目录保持原数据与功能选择。

卸载可按分类明确选择保留或删除当前工作区内容，默认全部保留。分类由`resources/storage-layout.json`统一声明；下载音乐、外部路径、其他工作区和根目录的未知文件保留。默认位置与最近列表只在另行选择忘记时清除。手动删除前应完全退出软件并备份需要保留的内容。

在线歌曲资料、歌词查询、模型或组件下载会向对应服务发起请求；请求可能包含歌曲标题、歌手等查询信息，以及网络连接通常暴露的 IP 地址。用户导入的在线音源脚本具有自己的网络行为，应自行核验来源。

日志、截图与诊断材料可能包含用户名、音乐路径、曲名和服务错误。提交公开 Issue 前应人工检查并脱敏，避免上传整个数据目录或音源配置。

清缓存与删除长期数据具有不同作用，操作前请阅读界面说明。备份应覆盖 `data/` 及用户另行指定的音乐和模型目录；先退出应用，避免复制尚在写入的数据库。

官方代码插件可来自随附归档或固定 GitHub Release，模型与计算环境从原发布者下载。请求包含包名、版本等资源标识，不附带本地曲库、路径、听歌记录或推荐行为。下载过程会向服务暴露通常的网络连接信息。移除插件或卸载安装版保留本地模型、索引和分析成果，可在功能选装页打开实际目录。
