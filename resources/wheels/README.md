# 随附的纯 Python 依赖

这些上游版本只提供源码归档。此处保留由原归档构建的通用 wheel，避免用户安装功能时还需要编译环境；原许可保留在各 wheel 内。

- antlr4-python3-runtime 4.9.3：[原始发行](https://pypi.org/project/antlr4-python3-runtime/4.9.3/)
- pretty-midi 0.2.11：[原始发行](https://pypi.org/project/pretty-midi/0.2.11/)
- MuQ 0.1.0：[原始发行](https://pypi.org/project/muq/0.1.0/)，原始归档 SHA256 为 `67ebb47d238e702151253d08e83e2dbbbe89d24c414b5b410d9b3db55c4a6fa8`。

制品 SHA256 固定于 `resources/catalog.json` 及环境锁文件；构建时和安装时均核验。
