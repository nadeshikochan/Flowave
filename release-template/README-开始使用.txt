Flowave ZIP 便携预览版

1. 完整解压 ZIP，再运行 Flowave.exe。不要在压缩包内直接双击。
2. 在歌曲页选择音乐文件夹，或进入“设置 > 曲库与在线”设置目录。
3. 在“设置 > 插件与模型”点击安装需要的功能。软件自动安装插件代码、匹配的模型和独立运行环境，无需另装 Python 或运行脚本。
4. 下载和校验完成后，完全退出再打开软件。模型处理需要兼容的 NVIDIA 显卡和驱动；基础播放无需模型。
5. 下载中可以取消，再次安装会复用已校验的文件。请按页面实际进度等待，失败时保留已有版本。
6. 安装歌曲推荐会同时准备MERT、MuQ/Essentia和对应计算环境。重启后，在“设置 > 歌曲推荐 > 准备与索引”更新全库索引，一次准备声音向量、语义与标签、地图。有效结果自动复用，歌曲分析界面可按需另装。
7. 不内置在线音源；需要时在“设置 > 在线音源”自行导入脚本。

个人设置、索引、记录和结果位于 data；插件代码在 data/packages/official，下载的模型和运行环境在 data/components/resources。
移除插件保留这些重要数据。可在数据与帮助的工作区与存储中打开实际目录，退出软件后自行整理。
迁移或备份时先关闭软件及后台，再复制整个程序目录。升级请解压到新目录后复制原 data，不覆盖运行中的文件。
此预览未签名；程序ZIP与资源大小、SHA256分别随构建和下载清单核验。
