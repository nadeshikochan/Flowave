Flowave ZIP 便携版

1. 完整解压 ZIP，再运行 Flowave.exe。
2. 在「设置 → 音乐库与在线 → 本地音乐」添加音乐文件夹。
3. 需要推荐、分析、演奏或听歌记录时，在「设置 → 插件与模型」安装对应插件。安装完成后重启。

工作区默认在程序旁的 data 目录。升级时把新版本解压到新目录，再从左下角「工作区」打开原工作区。备份和移动前先退出 Flowave。

软件内「使用手册」提供图文步骤，按 F1 可查看当前页面的说明。
