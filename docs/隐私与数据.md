# 隐私与数据

Flowave 无需账户。曲库、歌单、听歌记录和分析结果保存在本机。音频文件留在原目录。

## 数据位置

- **安装版** 使用安装时选择的数据目录。当前位置和最近打开的工作区记录在 `%LOCALAPPDATA%\Flowave`。
- **便携版** 默认使用程序旁的 `data`。
- **源码版** 通过程序目录中的 `workspace-location.txt` 记录当前工作区位置。

可以在「设置 → 数据与帮助 → 工作区与存储」打开实际目录。卸载默认保留工作区。移除插件也会保留记录、模型、索引和处理结果。

## 网络访问

查找歌曲资料和歌词时，软件会向资料来源发送必要的搜索字段，例如歌名和歌手。下载安装插件和模型时，会访问 GitHub 或模型发布者的服务。由你导入的在线音源脚本有自己的网络行为。

本机后台限定在本机监听。在应用与后台之间使用当前工作区的访问凭据。请勿分享工作区中的 `electron/backend-access-token` 文件。

## 诊断导出

「设置 → 数据与帮助 → 诊断日志」可以预览后导出。诊断包含版本、插件、资源状态和近期错误。导出会隐藏常见凭据和绝对路径，提交前请核对预览，避免分享整个工作区。
