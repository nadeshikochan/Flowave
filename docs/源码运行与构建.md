# 源码运行与构建

## 基础播放环境

Windows 10/11 x64、Node.js 24、Python 3.11，以及 Git。以下命令在 PowerShell 中执行。

```powershell
git clone https://github.com/nadeshikochan/Flowave.git
cd Flowave
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-public-backend.txt
$env:KUMIKO_PYTHON = (Resolve-Path .\.venv\Scripts\python.exe).Path
cd electron-lxplayer
npm ci
npm start
```

Electron 会尝试启动本机后端。`KUMIKO_PYTHON` 指定本次终端会话使用的解释器；相关内部命名用于兼容。应用启动后再添加本地音乐目录。

此处安装的是基础后端依赖，支持播放和曲库入口，不包含所有推荐、分析或演奏环境。当前源码快照未完成全新机器安装验收。

## 推荐与其他模型功能

- 推荐环境声明见 `requirements-recommendation-engine.txt`，PyTorch/torchaudio 需按硬件和构建脚本选择匹配版本；MERT 模型可参考 `scripts/install-model.ps1`。
- 标签分析、结构与分轨依赖分别见 `requirements-analysis.txt`、`requirements-structure.txt`、`requirements-stems.txt`。
- 上述文件并非演奏全部模型和外部工具的一键安装方案。旋律识别等能力仍需对应模型、外部运行时及可核验的组件清单；不要将研究缓存作为安装来源。
- 不含模型权重、音乐或第三方在线音源脚本。下载与使用前核对各组件许可。

## 检查与构建入口

在仓库根目录可执行静态边界检查：

```powershell
powershell -NoProfile -File scripts/verify-public-source.ps1
powershell -NoProfile -File scripts/verify-release-data.ps1 -DataDir release-template/data
```

Electron 的 `npm run check` 包含语法检查和 Node 测试；测试入口位于 `electron-lxplayer/test/`。Python 的开发依赖见 `requirements-dev.txt`；本仓库未提供完整 Python 回归测试集。

当前 ZIP 便携版使用 `scripts/build-portable.ps1`，需要 Windows x64、Node、Git 和 `uv`。脚本准备固定 Python 3.11.14 构建环境，按哈希锁安装后端依赖，打包轻量 API 和 Electron，并检查实际 ASAR 的依赖、资源清单和干净数据模板，生成 ZIP 与 SHA256。程序用户无需另装 Node、Python 或构建工具。

```powershell
./scripts/build-portable.ps1
# 本机 npm ci 已完成且依赖未变时
./scripts/build-portable.ps1 -SkipNpmInstall
```

构建结果位于 `electron-lxplayer/dist/portable-时间/`；`build/portable-delivery/latest-build.json`记录具体路径和源码状态。每次创建独立输出目录，测试配置和模型不会进入下一份 ZIP。脚本不会自动启动播放器、处理音乐或上传 Release。

`scripts/build-windows.ps1`与独立推荐组件脚本属于早期发行入口，尚未迁移到本轮资源流程；本轮不使用它们发布程序或构建 NSIS。

本仓库没有自动发布工作流。安装、卸载、便携数据隔离、硬件输出、重启和模型功能需要独立 Windows 验收后再发布。

已知构建缺口：`package.json` 的 NSIS 配置引用 `electron-lxplayer/build/installer.nsh`，当前源码未包含此文件，安装包构建会因此受阻。恢复并审查安装钩子后才能验收安装版；不要将构建脚本的存在视为可直接交付安装包。

## 目录

| 路径 | 内容 |
|---|---|
| 根目录 Python 文件 | 本机 API、曲库、推荐与任务处理 |
| `electron-lxplayer/` | 桌面窗口、播放界面、歌词及资料服务 |
| `packaging/` | 后端与索引组件的打包定义 |
| `scripts/` | 构建、模型安装与公开边界检查 |
| `release-template/` | 发行数据模板和第三方说明 |
| `docs/` | 使用、隐私和源码运行说明 |
