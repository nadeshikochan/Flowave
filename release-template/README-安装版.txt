Flowave Windows 安装版

1. 运行 Setup.exe，分别选择程序目录和数据目录。
2. 启动 Flowave，在「设置 → 音乐库与在线 → 本地音乐」添加音乐文件夹。
3. 需要推荐、分析、演奏或听歌记录时，在「设置 → 插件与模型」安装对应插件。安装完成后重启。

升级前退出 Flowave。运行新安装包时选择现有工作区，即可继续使用原有设置和记录。卸载默认保留数据。需要整理时，可从「设置 → 数据与帮助 → 工作区与存储」打开数据目录。

软件内「使用手册」提供图文步骤，按 F1 可查看当前页面的说明。
