# 源码运行与构建

## 从源码运行

需要 Windows 10/11 x64、Git、Node.js 24 和 Python 3.11。在 PowerShell 中执行：

```powershell
git clone https://github.com/nadeshikochan/Flowave.git
cd Flowave
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-public-backend.txt
$env:KUMIKO_PYTHON = (Resolve-Path .\.venv\Scripts\python.exe).Path
cd electron-lxplayer
npm ci
npm start
```

Electron 启动时会使用指定的 Python 解释器运行后台服务。推荐、分析和演奏所需的模型可在软件内通过「设置 → 插件与模型」安装。

## 构建 Windows 程序

需要安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)。在仓库根目录运行：

```powershell
./scripts/build-installer.ps1
./scripts/build-portable.ps1
```

安装包和 ZIP 分别输出到 `electron-lxplayer/dist/installed-时间/` 和 `electron-lxplayer/dist/portable-时间/`。目录包含文件校验值。发布版的安装包和 ZIP 应从同一个提交构建。

构建脚本准备 Python 3.11.14 环境并按锁文件安装依赖。安装版使用 Inno Setup。启用签名时，将 `FLOWAVE_SIGN_CERT_SHA1` 设为当前用户证书库中有效代码签名证书的指纹，并安装 Windows SDK 的 SignTool。

## 代码目录

| 路径 | 内容 |
| --- | --- |
| `electron-lxplayer/` | 桌面窗口、播放、歌词和界面 |
| `electron-lxplayer/official-modules/` | 官方插件源码和版本目录 |
| 根目录的 Python 文件 | 本机服务、曲库、推荐与模型任务 |
| `resources/` | 资源清单及模型运行环境锁定 |
| `packaging/` | Windows 安装及后台程序打包 |
| `scripts/` | [构建脚本](../scripts/README.md) |
