Flowave Windows 安装版

运行 Setup.exe，分别选择程序位置和软件数据存储位置。默认安装给当前用户。
打开 Flowave，在设置中添加音乐目录，即可使用基础播放器。
在“设置 > 功能选装”点击安装所需功能，软件自动准备插件、模型、运行环境和工具。
功能安装完成后，完全退出并重新打开软件。

个人设置、歌单、听歌记录、插件、模型和运行环境、索引、分析结果、分轨、轨迹、下载和缓存均存放在安装时选择的数据文件夹。
模型、分轨与缓存会持续占用空间，请选择空间充足的非系统盘。
系统用户目录只保存很小的数据目录位置记录。
更换数据位置可以重新运行安装包选择空目录，已有数据先复制并校验，成功后切换。原文件保留供核对和手动整理。

升级可运行新版本安装包。先完全退出播放器，等待保存完成。
卸载程序保留个人数据和计算资源，重新安装后可继续使用。
卸载窗口默认选中全部保留，可分别取消保留设置记录、处理成果、模型组件或缓存。
取消保留的分类会被删除。下载的音乐和其他工作区始终保留。
可另选忘记默认工作区与最近列表；它只清除位置记录。
需要整理时，可在功能选装页面打开实际数据目录，退出软件后再操作。

需要便携使用请下载 ZIP 便携版。已有便携目录可继续独立使用。
此安装包用于测试，当前未签名。音乐处理需要兼容的 NVIDIA 显卡与驱动。
模型与第三方组件的使用范围见 THIRD_PARTY_NOTICES.txt。
蓝牙耳机保护默认关闭，可在“设置 > 播放与声音”开启。
