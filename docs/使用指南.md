# 使用指南

## 软件内图文手册

左下角“使用手册”提供离线图文说明，包含功能入口、操作步骤、设置的调整逻辑和深入讲解。可搜索功能名称或问题，点击图片放大，使用文章内的按钮前往对应功能。设置中的“本页帮助”和 F1 可打开当前页面的说明。

图中编号对应控件说明。需要调整时，可查“遇到这些需要，怎样调整”；想了解模型、索引和分析结果的关系，可查同名术语文章。歌曲分析和音乐处理分别说明查看结果、选择范围及失败重试。

全新工作区首次启动会显示简短引导，介绍添加音乐、基本播放、可选功能与手册位置。完成或跳过后按工作区保存，已有工作区可在手册中重新打开入门引导。

## 开始播放

安装包和 ZIP 按发布页随附说明使用。源码运行方式见[源码运行与构建](源码运行与构建.md)，具体发行版本与文件见 [Releases](https://github.com/nadeshikochan/Flowave/releases)。

1. 打开“设置 → 音乐库与在线 → 本地音乐”，添加音乐目录并点击“应用更改”。
2. 在歌曲页搜索和播放，或创建歌单、浏览文件夹并安排队列。
3. 根据需要选择外观主题、歌词显示、桌面歌词和快捷键。

移除曲库目录不会删除其中的音频文件。处理大量文件前建议备份配置与音乐标签。

安装版运行 Setup.exe 后，分别选择程序位置和软件数据存储位置。设置、歌单、听歌记录、插件、模型环境、索引、分析、分轨、轨迹、下载和缓存都放入所选数据文件夹。模型、分轨与缓存会持续占用空间，建议选择空间充足的非系统盘。系统用户目录只保存很小的位置记录。

升级前完全退出播放器，再运行新安装包。安装器提供“新建工作区”“使用现有工作区”“复制已有数据”三种选择，新装默认新建，已有数据需要继续使用时选择原目录。复制迁移会先校验再切换，原文件保留。卸载默认保留数据与位置记录，重装可以打开原工作区。ZIP便携版默认使用程序旁`data`，实际目录可在“设置 → 数据与帮助 → 工作区与存储”查看。

## 工作区

点击左侧底部“工作区”，或进入“设置 → 数据与帮助 → 工作区与存储”。可以新建空工作区、打开已有数据文件夹，或从“最近打开”切换。原有Flowave数据目录可以直接打开。

每个工作区保存各自的音乐目录、歌单、设置、记录、插件选择、模型、索引和处理结果。新建工作区从基础播放器起步，音乐原文件仍按配置的路径读取。

切换前保存设置、播放记录和待写入内容，随后重新启动软件。计算或安装任务进行中时，请先完成或取消。保存失败保留当前工作区，目标目录不可用或版本不兼容时显示具体原因。新界面完成初始化后才保存默认位置。最近列表仅记录路径，切换不复制整套模型或合并歌曲数据。

便携版的内部工作区采用相对位置记录，整个便携目录移动后仍可读取。目录缺失时，启动恢复窗口可打开其他工作区或新建空工作区。备份应覆盖完整工作区，人工整理前退出软件。

## 连续推荐

在“设置 → 插件与模型”安装歌曲推荐，软件会自动准备MERT、MuQ/Essentia、计算环境与音频工具。完成后重启，在“设置 → 歌曲推荐 → 准备与索引”更新全库索引，依次建立声音向量、语义与标签、声音地图。已有有效结果会复用；页面显示阶段、进度与失败情况。歌曲分析界面可按需另装。

连续推荐可延续当前方向、找回听感或切换方向；复合种子用于组合歌曲偏好，声音地图用于浏览相似关系。推荐受曲库覆盖与分析结果影响，不能保证每次切换都符合个人听感。

## 可选功能

打开“设置 → 插件与模型”，点击歌曲推荐、歌曲分析、演奏练习或听歌记录旁的安装按钮。安装会自动获取插件代码、匹配的模型、运行环境和工具；全部校验后保存下次启用，完全退出并重新打开软件生效。下载中可以取消，失败后再次安装可复用已校验文件，无需手动安装 Python 或运行脚本。

私有测试包随附官方代码插件，模型与环境从原发布者下载；其他发行配置可从固定 GitHub Release 获取同一代码包。仓库保持私有时，匿名 GitHub 下载仍不可用。代码来源以功能条目显示为准。

停用和移除不会删除记录、模型、索引或已有成果；“数据与存储位置”可打开实际目录，手动整理前请退出软件。当前插件版本由配套客户端的可信目录固定，更新客户端目录后可安装获准的新版本。模型与环境独立存储，一次安装自动准备，不在打开页面时下载。完整计算类功能和 ZIP 新用户流程仍在验收中，源码接入不代表全部实机验收完成。

## 蓝牙耳机保护与卸载

“设置 → 播放与声音 → 蓝牙耳机保护”默认关闭，按工作区保存。开启后，耳机断连或输出切换会暂停，明确上报双耳摘下后也会暂停，戴回可恢复有效的同曲播放。手动暂停、切歌、断连或关闭保护会取消戴回恢复。媒体键与歌词延迟校准独立使用。

卸载默认保留全部工作区内容。可分别取消保留设置与记录、索引与处理成果、插件与模型环境、缓存与浏览器会话，删除前会再次确认。只处理显示的当前工作区，下载音乐、外部音乐目录与其他工作区保留。可另选忘记默认工作区和最近列表，实际工作区仍按上述选择保留。含链接、未知格式或仍在使用的目录会阻止清理。

演奏页的分轨和谱面辅助需要额外模型与运行环境，自动识别结果请人工核对。不要将其作为准确原谱的替代来源。

## 常见问题

- 启动失败：便携版确认已完整解压，源码运行请核对构建文档。查看实际数据目录下 `logs/`，分享前脱敏。
- 没有推荐：确认功能已启用且重启生效，并检查模型、运行组件和索引是否就绪。
- 资料或歌词缺失：先检查本地标签与歌词，再按需查询在线资料；在线服务不保证覆盖全部音乐。
- 模型任务失败：核对该功能的模型、依赖与 GPU 要求，不要反复重试全库任务。
- 迁移或备份：完整备份 `data/`，音乐和模型目录若在外部需另外备份；不要在运行过程中移动正在写入的数据。

仍有问题可提交 [Issue](https://github.com/nadeshikochan/Flowave/issues)，附版本、Windows 版本、步骤和脱敏日志。

## 安装前检查

功能安装会先检查默认 CUDA 显卡、驱动和工作区所在磁盘。首次资源总量包括模型与计算环境，多个功能之间的共同文件会复用。页面的空间预算包含下载、解压和暂存，安装时会按目标磁盘是否支持硬链接重新核算。已完成的资源和下载文件会校验复用。

音乐处理需要支持 CUDA 12 的 NVIDIA 驱动。歌曲段落需要支持 BF16 的显卡，完整演奏需要至少 3800 MiB 显存。处理时还需要空闲显存，实际模型会再次检查环境。

## 备份、恢复和升级

在“数据与帮助 → 帮助与恢复”查看备份状态、打开自动备份或操作前快照。软件会在主文件损坏时尝试最近有效备份，配置的最近有效副本为`config/app.json.previous`。无法恢复时保留原文件并显示错误。

人工恢复先完全退出软件与后台，并复制当前工作区。听歌记录可将选定备份复制为记录目录中的`listening_history.json`，保留备份原件，重开后核对日期和时长。索引按元数据与向量的完整代校验，两个文件及其`.previous`副本应一起保留。完整工作区备份还需覆盖外部引用的音乐文件。

升级失败可以重新运行已验安装包并打开原工作区，恢复前核对工作区格式兼容性。移动工作区时先退出，再移动完整文件夹，并通过“打开工作区”选中位置，外部音乐路径按实际位置重新选择。

## 版本和诊断

“数据与帮助 → 帮助与恢复”显示软件版本和构建号。报告问题请同时提供复现步骤。

“数据与帮助 → 诊断日志”可以生成诊断预览，核对本机版本、插件、资源、媒体事件和近期错误，再导出JSON文件自行提交。导出会隐藏本地绝对路径、请求路径和常见凭据字段，提交前仍请检查预览内容。

## 使用许可和预览版签名

Flowave主程序允许个人非商业长期使用，原始代码、图形和文档保留所有权。模型分别遵守原作者许可，具体以安装条目和THIRD_PARTY_NOTICES.txt为准，部分分轨权重的授权仍在核实。

本轮私有预览包如显示“未知发布者”，请核对官方发布页、文件名和SHA256。签名状态随构建记录提供，签名需要维护者自己的有效代码签名证书。
