# 使用指南

## 开始播放

当前仓库提供源码，运行方式见[源码运行与构建](源码运行与构建.md)。官方安装包发布后请从 [Releases](https://github.com/nadeshikochan/Flowave/releases) 获取，以实际发行文件和说明为准。

1. 打开设置，添加本地音乐目录并确认载入。
2. 在歌曲页搜索和播放，或创建歌单、浏览文件夹并安排队列。
3. 根据需要选择外观主题、歌词显示、桌面歌词和快捷键。

移除曲库目录不会删除其中的音频文件。处理大量文件前建议备份配置与音乐标签。

安装版运行 Setup.exe 后，分别选择程序位置和软件数据存储位置。设置、歌单、听歌记录、插件、模型环境、索引、分析、分轨、轨迹、下载和缓存都放入所选数据文件夹。模型、分轨与缓存会持续占用空间，建议选择空间充足的非系统盘。系统用户目录只保存很小的位置记录。

升级前完全退出播放器，再运行新安装包，原数据位置会自动填入。更换数据位置时请选择空文件夹，安装器先复制并校验已有数据，成功后切换，原文件保留供核对和手动整理。卸载保留数据及位置记录，重装可继续使用。ZIP便携版使用程序旁`data`。在“功能选装 → 数据与存储位置”可打开实际目录。

## 工作区

点击左侧底部“工作区”，或进入“设置 → 功能选装 → 工作区”。可以新建空工作区、打开已有数据文件夹，或从“最近打开”切换。原有Flowave数据目录可以直接打开。

每个工作区保存各自的音乐目录、歌单、设置、记录、插件选择、模型、索引和处理结果。新建工作区从基础播放器起步，音乐原文件仍按配置的路径读取。

切换前保存设置、播放记录和待写入内容，随后重新启动软件。计算或安装任务进行中时，请先完成或取消。保存失败保留当前工作区，目标目录不可用或版本不兼容时显示具体原因。新界面完成初始化后才保存默认位置。最近列表仅记录路径，切换不复制整套模型或合并歌曲数据。

便携版的内部工作区采用相对位置记录，整个便携目录移动后仍可读取。目录缺失时，启动恢复窗口可打开其他工作区或新建空工作区。备份应覆盖完整工作区，人工整理前退出软件。

## 连续推荐

推荐需要匹配的模型、推荐运行组件及已完成的索引。源码中的基础后端依赖不包含所有模型依赖。准备好相应环境后，在设置中明确启动索引或分析；缺少组件时先使用基础播放。

连续推荐可延续当前方向、找回听感或切换方向；复合种子用于组合歌曲偏好，声音地图用于浏览相似关系。推荐受曲库覆盖与分析结果影响，不能保证每次切换都符合个人听感。

## 可选功能

打开“设置 → 功能选装”，点击歌曲推荐、歌曲分析、演奏练习或听歌记录旁的安装按钮。安装会自动获取插件代码、匹配的模型、运行环境和工具；全部校验后保存下次启用，完全退出并重新打开软件生效。下载中可以取消，失败后再次安装可复用已校验文件，无需手动安装 Python 或运行脚本。

私有测试包随附官方代码插件，模型与环境从原发布者下载；其他发行配置可从固定 GitHub Release 获取同一代码包。仓库保持私有时，匿名 GitHub 下载仍不可用。代码来源以功能条目显示为准。

停用和移除不会删除记录、模型、索引或已有成果；“数据与存储位置”可打开实际目录，手动整理前请退出软件。当前插件版本由配套客户端的可信目录固定，更新客户端目录后可安装获准的新版本。模型与环境独立存储，一次安装自动准备，不在打开页面时下载。完整计算类功能和 ZIP 新用户流程仍在验收中，源码接入不代表全部实机验收完成。

演奏页的分轨和谱面辅助需要额外模型与运行环境，自动识别结果请人工核对。不要将其作为准确原谱的替代来源。

## 常见问题

- 启动失败：便携版确认已完整解压，源码运行请核对构建文档。查看实际数据目录下 `logs/`，分享前脱敏。
- 没有推荐：确认功能已启用且重启生效，并检查模型、运行组件和索引是否就绪。
- 资料或歌词缺失：先检查本地标签与歌词，再按需查询在线资料；在线服务不保证覆盖全部音乐。
- 模型任务失败：核对该功能的模型、依赖与 GPU 要求，不要反复重试全库任务。
- 迁移或备份：完整备份 `data/`，音乐和模型目录若在外部需另外备份；不要在运行过程中移动正在写入的数据。

仍有问题可提交 [Issue](https://github.com/nadeshikochan/Flowave/issues)，附版本、Windows 版本、步骤和脱敏日志。
